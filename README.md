# Santi — Portfolio

Portfolio personal de Santi, estudiante de la Licenciatura en Negocios Digitales.

Este proyecto reúne trabajos académicos, proyectos personales y desarrollos digitales relacionados con diseño, tecnología, analítica y negocios digitales.

## Sobre el proyecto

El portfolio fue desarrollado como un espacio para presentar proyectos y experiencias de forma clara, simple y visual.

El objetivo es mostrar no solo los resultados de cada proyecto, sino también las herramientas y tecnologías utilizadas durante su desarrollo.

## Proyectos destacados

### NativoMates

Desarrollo de una página web para un emprendimiento comercial.

El proyecto contempla estructura web, diseño visual, experiencia de usuario y desarrollo frontend, incorporando herramientas de medición y analítica digital.

**Tecnologías:** HTML · CSS · JavaScript · Google Tag Manager · Google Analytics 4

[Ver proyecto](https://nativomates.github.io/NativoMates/)

---

### DISTRIMAT

Desarrollo de una página web para una distribuidora especializada en cintas adhesivas y soluciones de embalaje.

El sitio presenta productos, cobertura y modalidades de atención, con foco en facilitar consultas, cotizaciones y pedidos de comercios y empresas.

**Tecnologías:** HTML · CSS · JavaScript · Google Tag Manager · Analytics

[Ver proyecto](https://distrimat.github.io/distrimat/)

---

### Buscador de Jugadores

Aplicación web desarrollada a partir de un proyecto de análisis de datos en Python.

Permite explorar y filtrar información de jugadores de Primera Nacional según equipo, posición, edad y valor de mercado.

**Tecnologías:** Python · Pandas · Streamlit · CSV
